## 🌟 Fitur Utama

- **Live Interactive Mentoring via Zoom**: Sesi tatap muka virtual dua arah bersama mentor peraih medali OSN.
- **Kurikulum & Bank Soal HOTS Bertingkat**: Modul digital berjenjang (*Basic*, *Intermediate*, *Advanced*) sesuai silabus resmi OSN-K, OSN-P, dan Nasional.
- **Small Class (10–15 Siswa) & Klinik Soal**: Perhatian mentor merata dengan klinik soal mingguan untuk bedah materi.
- **Simulasi CBT & Laporan Diagnostik Berkala**: Try-out berbasis Computer-Based Test dengan sistem penilaian standar nasional dan rapor analitik untuk orang tua.
- **Interactive Whiteboard HOTS Simulation**: Bedah soal interaktif langsung pada landing page (*Matematika OSN, Fisika & Sains, Penalaran TKA*).

## 🎨 Design Direction & Framework Anti-Slop

Proyek ini dibangun mengikuti panduan kualitas dari framework [anti-slop](https://github.com/miqdadbadjuber/anti-slop):
- **Dokumentasi Desain:** Tersedia pada file [`DESIGN.md`](./DESIGN.md).
- **Hasil Audit Kualitas:** Tersedia pada file [`anti-slop-delivery-gate.md`](./anti-slop-delivery-gate.md) dengan status **ALL CHECKS PASS**.
- **Dial Settings:** `ENERGY 2 / RHYTHM 2 / MOTION 2` (Intelektual, terstruktur, dan fungsional).
- **Palet Warna:**
  - Primary: Deep Navy Blue (`#0F172A`)
  - Accent 1: Emerald Green (`#10B981`)
  - Accent 2: Warm Gold (`#F59E0B`)
  - Background: Clean White (`#FFFFFF`) & Soft Slate (`#F8FAFC`)

## 🚀 Memulai Proyek (Getting Started)

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas disarankan)
- npm / yarn / pnpm

### Instalasi & Menjalankan

1. **Clone repository:**
   ```bash
   git clone https://github.com/TricQs/tunascendekia.git
   cd tunascendekia
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan pada `http://localhost:3000`.

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```

5. **Pratinjau build produksi:**
   ```bash
   npm run preview
   ```
